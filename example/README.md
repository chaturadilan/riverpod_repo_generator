# Example

This folder demonstrates `riverpod_repo` against a sample `RepoData` repository.

## Files

| File | Role |
|------|------|
| `example.dart` | Repository interface, `@Riverpod` provider, and implementation |
| `example.g.dart` | Generated by `riverpod_generator` (hand-written `@Riverpod` only) |
| `example.repo.g.dart` | Generated by `riverpod_repo` (one provider per query method) |
| `student.dart`, `country.dart` | Model types referenced in method signatures |

## What gets generated

`RepoData` defines six methods. **`deleteBook`** is a mutation (`Future<void>`) and
is **not** turned into a provider.

Generated query providers:

- `repoDataGetBooksProvider` — record family `(search, categoryId)`
- `repoDataGetTopGenresProvider` — auto-dispose (overrides class `keepAlive`)
- `repoDataGetTopBooksByGenreProvider` — record family
- `repoDataGetCategoriesProvider` — record family
- `repoDataGetCountryProvider` — `String` family

After mutations, call:

```dart
invalidateRepoDataProviders(ref);
```

## Regenerate

From the repository root:

```bash
dart run build_runner build
```

## Usage in an app

```dart
import 'example.repo.g.dart';

// In a ConsumerWidget:
ref.watch(repoDataGetCountryProvider('LK'));

ref.watch(repoDataGetBooksProvider((search: 'dart', categoryId: '1'))).when(
  loading: () => ...,
  error: (e, _) => ...,
  data: (books) => ...,
);
```
